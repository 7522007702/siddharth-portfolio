01 / FOUNDATION

What is a Computer?

A computer is an electronic programmable machine that accepts data, processes it according to instructions, stores it and produces useful information as output.

FOUNDATION
DEFINITION

Computer System

A computer system is a combination of hardware, software, data, users and procedures working together to perform computational tasks.

Input Data or instructions supplied to the computer.
Processing CPU and other components transform data.
Output Processed information presented to the user.
Storage Data and programs are retained for future use.

02 / CLASSIFICATION

Types of Computers

Computers can be classified according to size, processing capability, purpose and the type of data they process.

GENERAL PURPOSE

Personal Computers

Desktop computers and laptops are general-purpose systems used for programming, education, office work, entertainment and communication.

MOBILE

Smartphones & Tablets

Mobile computers combine processors, memory, storage, networking, sensors and touch interfaces into portable devices.

LARGE SCALE

Servers & Mainframes

Servers provide services to clients over networks. Mainframes are designed for very large transaction processing workloads.

HIGH PERFORMANCE

Supercomputers

Supercomputers use massive parallel processing for scientific simulations, weather modelling, research and other computationally intensive tasks.

EMBEDDED

Embedded Computers

Embedded systems are computers built into larger products such as cars, appliances, industrial machines and medical equipment.

DATA TYPES

Analog, Digital & Hybrid

Analog computers work with continuous values, digital computers work with discrete values, and hybrid systems combine characteristics of both.

The CPU is the primary instruction-processing component. Its major conceptual parts include the Control Unit, ALU and registers.

CPU COMPONENTS

Coordinates instruction execution and control signals.

Performs arithmetic and logical operations.

Very fast small storage locations inside the processor.

INSTRUCTION CYCLE
FETCH Get instruction
→
DECODE Interpret instruction
→
EXECUTE Perform operation
→
STORE Save result
COMPUTER ARCHITECTURE

In the classical Von Neumann model, instructions and data share memory. A Harvard architecture conceptually uses separate instruction and data memories. Modern processors can combine ideas from both approaches.

instruction_cycle.txt 
while (program_is_running) {

    instruction = fetch(memory, program_counter);

    decoded = decode(instruction);

    result = execute(decoded);

    store(result);

    program_counter++;
}

20 / HISTORY

Computer Generations

Computer technology evolved through major hardware transitions, from vacuum tubes to modern microelectronics and highly integrated systems.

FIRST GENERATION

Vacuum Tubes

Early electronic computers used vacuum tubes and were large, expensive and power-hungry.

SECOND GENERATION

Transistors

Transistors replaced vacuum tubes in many systems, improving size, reliability and efficiency.

THIRD GENERATION

Integrated Circuits

Multiple electronic components were integrated into semiconductor chips.

FOURTH GENERATION

Microprocessors

CPU functionality became highly integrated into microprocessors, enabling widespread personal computing.

MODERN ERA

Connected & Intelligent Computing

Modern systems combine multicore processors, GPUs, cloud infrastructure, AI accelerators, networking and intelligent software.

21 / PRACTICAL KNOWLEDGE

Troubleshooting & Maintenance

Basic troubleshooting starts by identifying the symptom, isolating the possible cause and testing solutions systematically.

SYSTEMATIC APPROACH
1. Identify Clearly describe the problem.
2. Observe Check messages, sounds, lights and recent changes.
3. Isolate Narrow the problem to hardware, software, network or user configuration.
4. Test Apply one change at a time.
5. Verify Confirm that the original problem is solved.
