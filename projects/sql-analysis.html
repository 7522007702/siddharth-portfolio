CASE STUDY 03 DATABASE • ANALYSIS

SQL Data Analysis.

A query-driven analytical project demonstrating filtering, aggregation, grouping, joins, ranking and business-oriented data exploration.

analysis.sql 
SELECT
    customer,
    region,
    SUM(revenue)
        AS total_revenue,
    COUNT(order_id)
        AS total_orders

FROM sales

WHERE
    year = 2026

GROUP BY
    customer,
    region

HAVING
    SUM(revenue) > 50000

ORDER BY
    total_revenue DESC;

Filtering

WHERE conditions used to isolate relevant records for analysis.

Aggregation

SUM, COUNT, AVG and other functions transform rows into useful metrics.

Joins

Multiple data sources can be connected through relational logic.

Ranking

ORDER BY and analytical logic identify high-performing entities.

analytics.sql 
WITH ranked_sales AS (

    SELECT
        customer,
        revenue,

        RANK() OVER(
            ORDER BY
            revenue DESC
        ) AS revenue_rank

    FROM sales
)

SELECT *
FROM ranked_sales
WHERE revenue_rank <= 10;
